Vehicle Management System
Made by Caitlyn Barden
CSC 2110 Lab Section 003

Description: This is a text-based vehicle store management system for cars, trucks, and motorcycles. All vehicles are stored polymorphically using a single linked list.

Files in the Program:
main.cpp - Displays main menu and stores input validation functions
Vehicle.h and Vehicle.cpp - Abstract base class with virtual functions
Car.h and Car.cpp - Derived Class (doors and fuel type)
Truck.h and Truck.cpp - Derived Class (payload capacity, four-wheel drive)
Motorcycle.h and Motorcycle.cpp - Derived Class (engine CC, sidecar)
Node.h - List Node
VehicleList.h and VehicleList.cpp - Custom linked list
